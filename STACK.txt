GLYDI — TECHNICAL STACK
=======================

A machine in a room: sees, hears, remembers, and holds a spoken
conversation with the people in front of it. Everything local.

Repo: github.com/glydi/bot
Platform: macOS (Apple Silicon)
Runtime: Rust (rust/). Python is a bench (bench/), never at runtime.


THE LOOP
--------

  camera ─┐                              ┌─ speaker (AVSpeech / Kokoro)
  mic ────┼─ Observation ─▶ MIND ─ Command ─┼─ face window (egui/wgpu)
  (any) ──┘                              └─ (later: a body)

  MIND
    reflex       one thread, <1 ms, allocation-free: attend, barge-in,
                 backchannel, planner.  Never waits on the slow path.
    world        entities PRESENT/ABSENT, events ENTERED/LEFT/RETURNED/
                 SAID, beliefs (categorical, decaying), working memory,
                 goal stack.
    deliberate   tokio; LLM turn with tools; cancelled by a reflex.

  Latency, measured: observation -> command p99 10 us (release).


COMPONENTS
----------

  Turn detection   smart-turn v3.2 (ONNX)                    sense-audio
  Speech to text   whisper.cpp tiny.en via whisper-rs (Metal) sense-audio
  Speaker id       ECAPA-TDNN ONNX, 192-d, cosine 0.55/0.08   sense-audio
  Face detect      InsightFace SCRFD-500M (ONNX)              sense-vision
  Face embed       MobileFaceNet w600k, 512-d, 0.36/0.06      sense-vision
  Camera           AVFoundation via objc2, 15 fps             sense-vision
  Language model   qwen2.5:3b via Ollama (OpenAI API)         deliberate
  Text to speech   macOS AVSpeech via rust/ttsd (default)     act-speaker
                   Kokoro v1.0 af_bella, ONNX (--features kokoro)
  Memory           SQLite (rusqlite) + in-memory matrices     memory
  Inference        ONNX Runtime 1.29 (Homebrew dylib, `ort`)  all
  Window           egui + eframe (wgpu)                       act-ui
  Audio I/O        cpal                                       sense-audio, act-speaker
